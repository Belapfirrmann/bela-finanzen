nicht verbunden

Für Live-Kurse und Nachrichten braucht die App ein kleines Zwischenstück, weil eine reine Webseite die Börsendaten nicht direkt abfragen darf. Kein API-Schlüssel nötig, nur ein kostenloser Cloudflare-Account.

Anleitung: in zehn Minuten eingerichtet
  1. Auf dash.cloudflare.com kostenlos anmelden.
  2. Links auf Compute (Workers), dann Create und Start with Hello World! wählen, unten Deploy drücken.
  3. Oben auf Edit code. Den gesamten Beispielcode markieren und löschen.
  4. Hier auf Worker-Code kopieren tippen und im Cloudflare-Editor einfügen. Dann Deploy.
  5. Zurück auf der Worker-Seite unter Settings → Variables and Secrets → Add die Variable ALLOWED_ORIGINS anlegen, Wert: die Adresse, unter der du diese App öffnest.
  6. Die Adresse des Workers (endet auf .workers.dev) unten eintragen und auf Prüfen tippen.
